# Canonical Blueprint

Canonical Blueprint v1.0 defines a 17-chapter, five-part practitioner handbook targeting roughly 620-700 manuscript pages plus appendices. This replaces the earlier 44-chapter structure and supersedes every prior Chapter 1-3 outline; earlier prose is not an unassigned source bank, not canonical manuscript text.

### Contested Terrain: Offensive and Defensive Operations in Federal Active Directory Environments

**Book Contract**

This is a practical security-operations handbook for authorized defenders, assessors, incident responder, ethical hackers, and red/purple/blue-team personnel working in federal, defense, critical-infrastructure, or comparably regulated Active Directory environments.

The book's differentiator is not that it covers Active Directory attacks alone. It connects:

* Active Directory and enterprise PKI mechanics.
* Federal identity context: FICAM, DoD ICAM, PIV/CAC, RMF, STIGs, and mission assurance.
* Authorized adversary emulation.
* Detection engineering and hunting.
* Containment, recovery, and restoration of identity trust.
* Hybrid identity and federation.

Every technical chapter follows one fixed rhythm:

1. Mission context and identity function
2. Architecture and protocol mechanics
3. Authorized attack or adversary-emulation scenario
4. Evidence, telemetry, and detection logic
5. Hardening and containment
6. Validation and recovery implications
7. Lab exercise
8. Attack journal/Defender journal
9. Summary

"Attack walkthrough" means controlled lab or explicitly authorized assessment material. It must never be presented as an instruction to operate against systems outside a reader's authorization boundary.
