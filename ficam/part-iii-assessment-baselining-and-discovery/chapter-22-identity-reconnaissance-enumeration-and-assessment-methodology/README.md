# Chapter 22 - Identity Reconnaissance, Enumeration, and Assessment Methodology

### Abstract

Identity assessment begins before exploitation. This chapter establishes a disciplined methodology for discovering Active Directory, Microsoft Entra ID, PKI, hybrid identity, privileged-access, and management infrastructure while preserving scope, evidence quality, and mission safety. It distinguishes passive reconnaissance, active discovery, unauthenticated enumeration, authenticated enumeration, and adversarial validation, then examines how DNS, network services, directory metadata, Kerberos, LDAP, SMB, RPC, certificates, cloud endpoints, exposed applications, and administrative infrastructure reveal the identity control plane. Offensive analysis focuses on turning observations into hypotheses about authority, trust, privilege, credential exposure, and attack paths without prematurely escalating activity. Defensive analysis uses the same discovery process to identify unknown assets, exposed services, stale dependencies, undocumented trust relationships, and telemetry gaps before an adversary does. The chapter emphasizes collection discipline, confidence scoring, evidence preservation, rules of engagement, and iterative hypothesis testing. Reconnaissance is treated not as a preliminary checklist but as the first technical phase of identity security analysis: discovering what exists, determining what can be proven, and identifying where deeper enumeration is justified.
