# 2.5.2 Transitive Trust Extends Security Consequences

Trust relationships become more complicated when trust is transitive.

Transitivity allows trust to extend through relationships rather than requiring every domain to establish an independent direct trust with every other domain.

Operationally, this greatly improves scalability.

Security analysis must account for the resulting reach.

A principal does not need to originate in the same domain as a resource to influence that resource if the surrounding trust architecture allows the identity to be accepted and the resource grants it authority.

The practical security boundary therefore cannot be determined solely by examining the resource's local domain.

The analyst must understand the domains and forests from which trusted principals can arrive, the groups into which those principals can be nested, the SID information they carry, and the administrative systems capable of modifying those relationships.

This is one reason trust enumeration occurs early in an Active Directory assessment.

Trust defines where identity may travel.

Authorization determines what the identity can do after it arrives.
