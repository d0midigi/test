# 2.2.3 X.500 and Directory-Service Concepts

Active Directory also inherited concepts from the broader lineage of X.500 directory services.

The influence is visible in Active Directory's hierarchical naming, directory objects, attributes, Distinguished Names (DNs), schema, and use of Lightweight Directory Access Protocol.

This ancestry matters because Active Directory is not simply an account database with a graphical administrative interface.

It is a structured directory containing authoritative information about principals, systems, services, policies, and relationships.

The schema defines what kinds of objects can exist and what attributes those objects may possess. Distinguished Names place objects within the directory hierarchy. Naming contexts partition directory data. LDAP provides a standardized mechanism for querying and manipulating that information.

Those characteristics make Active Directory far more expressive than the flatter identity structures that preceded it.

They also make it far more valuable to an attacker.

A compromised directory does not reveal only usernames and password-related information. It exposes the relationships by which the enterprise defines itself: administrative delegation, group membership, service identities, trust relationships, computer objects, policy references, certificate-related configuration, and numerous attributes that influence authentication and authorization.

The directory is simultaneously an operational database and a map of authority.
