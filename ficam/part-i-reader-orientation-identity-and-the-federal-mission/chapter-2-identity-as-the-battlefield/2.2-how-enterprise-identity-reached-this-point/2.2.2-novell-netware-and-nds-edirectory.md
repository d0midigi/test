# 2.2.2 Novell NetWare and NDS/eDirectory

Microsoft was not the only vendor attempting to solve enterprise identity and directory problems.

Novell NetWare and Novell Directory Services, later known as eDirectory, were influential enterprise directory technologies and demonstrated the value of hierarchical, directory-based administration before Active Directory became dominant in Windows environments.

NDS organized network resources within a directory tree rather than relying solely on the flatter domain structures familiar to Windows NT administrators. The hierarchy allowed administrators to represent organizations, locations, users, groups, and resources within a more scalable directory model.

The comparison is historically useful because Active Directory did not emerge into a vacuum. Enterprise administrators were already confronting the need for scalable directory services, centralized identity management, replication, delegated administration, and distributed resource access.

The competition among these models reflected a larger industry transition: identity information was becoming infrastructure.

Once applications, file services, messaging systems, workstations, and administrative processes began depending upon directory state, the directory itself became increasingly critical to enterprise operation.

That dependence would later become security dependence.
