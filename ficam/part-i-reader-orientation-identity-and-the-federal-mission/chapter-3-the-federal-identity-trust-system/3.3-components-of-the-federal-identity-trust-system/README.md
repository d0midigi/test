# 3.3 Components of the Federal Identity Trust System

The federal identity trust system is not a single standardized deployment.

Agencies and commands differ in architecture, technology, mission, classification, age, cloud adoption, and administrative organization. Some environments remain heavily centered on traditional on-premises Active Directory. Others use substantial cloud identity and federation. Some rely extensively on enterprise services operated elsewhere. Tactical or disconnected environments may implement identity under constraints rarely encountered in commercial enterprises.

The model used here is therefore functional rather than product-specific.

The relevant components are those capable of establishing, representing, extending, modifying, or enforcing trusted identity.
