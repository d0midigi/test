# 3.3.1 Active Directory Domain Services

Active Directory Domain Services remains the most obvious component because it maintains directory objects and participates directly in Windows domain authentication and authorization.

AD DS provides the authoritative representation of many users, computers, groups, service accounts, policies, trusts, and other objects used throughout the Windows enterprise.

Its security significance extends beyond those objects individually.

The directory also records relationships.

Group membership expresses entitlement.

Access control expresses administrative authority.

Service Principal Names associate services with security principals.

Delegation configuration affects impersonation capability.

Trust objects connect security domains.

Computer accounts establish machine identity.

Group Policy links administrative configuration to systems.

These relationships turn directory state into operational authority.

Compromise of AD DS therefore threatens not only identity records but the mechanisms through which those records are interpreted across the enterprise.
