# 3.2.3 Authentication Boundaries Can Be Broader Than Directory Boundaries

A directory boundary defines where particular identity objects and administrative structures exist.

Authentication trust can extend beyond that boundary.

Forest trusts, external trusts, realm trusts, federation, certificate trust, cloud identity, and mission-partner relationships can all permit identities originating elsewhere to influence access.

The external identity does not become locally administered merely because it is trusted.

This creates an important security property: some principals capable of accessing a resource may not be controlled by the same administrative authority that controls the resource.

That condition is normal in federated and partner environments.

It also complicates incident response.

A local security team may identify malicious activity associated with a partner identity but lack authority to reset the originating credential. The response may require coordination with the external identity provider, revocation of local access, modification of trust configuration, or temporary restriction of the federation relationship.

The security boundary therefore includes coordination mechanisms as well as technology.
