# 3.2.4 The Trusted Core Extends Beyond Domain Controllers

Domain Controllers are unquestionably Tier 0 assets.

But treating Tier 0 as a synonym for Domain Controllers creates blind spots.

If a system can create equivalent authority over the directory, it belongs in the same security discussion.

A Certification Authority that can issue authentication certificates usable by privileged identities may become Tier 0-equivalent.

A synchronization platform with high privilege in Active Directory and the cloud may bridge two control planes.

A hypervisor capable of controlling Domain Controller virtual machines may circumvent protections placed inside those Domain Controllers.

A backup platform capable of restoring or manipulating directory state may possess recovery authority over the forest.

An endpoint-management platform capable of deploying code to Domain Controllers can become an indirect administrative path.

The trusted core must therefore be derived from control relationships rather than product names.

This principle becomes increasingly important later when the book formally examines Tier 0 and the extended trusted core.
