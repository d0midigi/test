# 5.8 Access Governance

Access governance determines how authenticated identity becomes authorized activity.

This is where the enterprise converts identity information into real capability.

In Active Directory environments, access governance is often associated with security groups because group membership is one of the most common ways to assign permissions at scale. That model remains important, but modern enterprise authorization extends far beyond groups.

Directory Access Control Entries can assign authority directly.

Application roles may exist outside Active Directory.

Cloud administrative roles may be eligible rather than permanently active.

Federated claims may influence authorization dynamically.

Attributes can drive policy.

Device state can participate in access decisions.

Service principals and workload identities can possess application permissions that have no direct equivalent in a traditional Windows group.

The governance problem is therefore not simply membership management.

It is entitlement management.
