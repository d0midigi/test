# 5.13.2 Strong Authentication Is Necessary but Not Sufficient

The connection between Zero Trust and modern authentication is strong because reusable passwords and weak authentication create obvious paths for adversaries to become trusted principals.

Phishing-resistant authentication substantially reduces important classes of identity attack.

But Zero Trust cannot stop at the authentication event.

If the authenticated principal has excessive authority, the security problem survives.

If the account is used from an inappropriate administrative workstation, the session may still be dangerous.

If a certificate was improperly issued, the authentication can be cryptographically excellent and operationally fraudulent.

If the endpoint is already compromised, successful phishing-resistant authentication may establish a high-assurance session on behalf of a user operating through an untrustworthy execution environment.

Modern authentication improves confidence in the claimant.

Zero Trust requires the architecture to consider what else must be true before granting the requested access.
