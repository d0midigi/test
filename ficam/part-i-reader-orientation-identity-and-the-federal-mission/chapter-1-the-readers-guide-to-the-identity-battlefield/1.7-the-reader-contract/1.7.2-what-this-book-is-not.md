# 1.7.2 What This Book Is Not

This is not an Active Directory administration manual.

Routine administrative procedures are explained only where they are necessary to understand identity security. The reader will learn how Group Policy, replication, trusts, authentication, and directory permissions work, but the book is not intended to replace Microsoft's operational documentation or a comprehensive Windows Server administration reference.

It is also not a catalogue of Active Directory hacking commands.

Offensive tools and procedures appear extensively, but the objective is to understand why a technique succeeds and what security relationship it exploits. A command that produces Domain Admin access without explaining the authority chain that enabled it is incomplete for the purposes of this book.

Nor is it a compliance checklist.

Federal governance, RMF, STIGs, SRGs, authorization evidence, and continuous monitoring are integral to the material because they shape how federal identity infrastructure is engineered and assessed. They are not treated as substitutes for adversarial validation.

A system can satisfy individual configuration requirements and still contain dangerous combinations of permissions, credentials, trust relationships, or administrative dependencies. Conversely, a technically concerning configuration may exist because of a documented mission requirement and require engineered compensating controls rather than simplistic removal.

Security posture has to be evaluated as a system.
