# 1.3.3 Basic Active Directory Familiarity

Previous exposure to Active Directory is useful, but the book does not assume that the reader has spent years administering a forest.

At the beginning, it is sufficient to understand Active Directory Domain Services (AD DS) as Microsoft's distributed directory and identity platform for Windows enterprise environments. It stores objects representing users, computers, groups, services, policies, and other directory entities; supports authentication; participates in authorization decisions; distributes configuration through Group Policy; and establishes trust relationships across domains and forests.

Readers with prior administrative experience will recognize early concepts such as domains, Domain Controllers, Organizational Units (OUs), security groups, Group Policy Objects (GPOs), sites, and trusts. Readers without that experience will encounter those concepts in much greater detail before the book uses them offensively.

What is more important than memorizing administrative interfaces is beginning to understand Active Directory as a system of authority.

A user object is not merely an account stored in a directory.

A group is not merely a container for users.

An OU is not merely an organizational folder.

A GPO is not merely a configuration object.

A trust is not merely a convenience allowing one domain to accept identities from another.

Each of these structures participates in an authority model.

A user can possess permissions over another object. A group can confer administrative capability. An OU can become a delegation boundary. A GPO can distribute security configuration or code. A trust can extend authentication beyond the local domain. A certificate template can create authentication authority. A synchronization service can extend on-premises privilege into the cloud or the reverse.

That shift—from viewing Active Directory as a collection of administrative objects to viewing it as a graph of control relationships—is one of the central conceptual changes this book will develop.
