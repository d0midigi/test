# Chapter 3 - Active Directory Network Foundations, Identity Communications, and Protocol Security

{% hint style="info" %}
Active Directory identity depends on secure network communications, protocol behavior, and deliberate trust boundaries. This chapter connects network architecture to identity assurance, monitoring, and defensive control.
{% endhint %}

### Abstract

Chapter 3 establishes the network foundation upon which Active Directory and federal identity services depend. Readers will examine addressing, routing, segmentation, ports, Dynamic Host Configuration Protocol (DHCP), Domain Name System (DNS), name-resolution fallbacks, IPv6, time synchronization, Server Message Block (SMB), Remote Procedure Call (RPC), Lightweight Directory Access Protocol (LDAP), Kerberos, NTLM, Remote Authentication Dial-In User Service (RADIUS), IEEE 802.1X, and Extensible Authentication Protocol (EAP). Particular attention is given to the security consequences of reachability, authentication fallback, insecure name resolution, relay opportunities, and insufficient network isolation.

Furthermore, Chapter 3 explains network segmentation from administrative and identity boundaries and examines identity communications across NIPRNet, SIPRNet, national-security, tactical, mission-partner, hybrid, and cloud environments. Host firewalls, telemetry, network detection, and validation are incorporated throughout. Rather than treating networking as a separate infrastructure discipline, the chapter demonstrates that every authentication, authorization, federation, and directory interaction ultimately traverses a communications path. Readers leave prepared to recognize when network paths become identity paths and when identity dependencies transform network design into a control-plane security concern.
