# 6.6.4 Windows Server 2025 Introduces Role-Aware Baseline Management Through OSConfig

Microsoft has continued evolving the baseline model for Windows Server 2025. Current Microsoft documentation provides role-aware Windows Server 2025 security baselines through OSConfig, including separate baseline application for Domain Controllers, member servers, and workgroup systems. OSConfig can apply, verify, customize, and maintain the applicable baseline, including configuration-drift control. Microsoft explicitly notes that this OSConfig baseline mechanism applies to Windows Server 2025 and is not supported for earlier Windows Server versions.

The role distinction is technically important.

A Domain Controller should not simply inherit a generic member-server hardening model.

The security function is different.

A Domain Controller has no conventional local account database equivalent to a member server's security model.

It participates in directory replication.

It runs authentication services integral to the domain.

It exposes directory protocols.

Its Group Policy requirements differ.

Its administrative boundary is fundamentally different.

Its compromise carries substantially greater identity consequence.

Role-aware baselines recognize that a secure configuration depends partly on what the server is expected to do.

That concept should extend beyond the Microsoft baseline itself.

A Certificate Authority requires a different security model from an ordinary application server.

A privileged-access server requires different administrative exposure from a general-purpose management host.

A synchronization server connecting Active Directory and Microsoft Entra ID requires protection based on the authority it possesses in both planes.

System role is part of identity risk.
