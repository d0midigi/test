# 5.15 Federal Cloud Governance

## 5.15 Federal Cloud Governance

### 5.15.1 Cloud Adoption Does Not Transfer Security Accountability

{% hint style="info" %}
Migration to cloud infrastructure changes responsibility boundaries but does not eliminate agency responsibility for identities, privileges, applications, configuration, and access policy.
{% endhint %}

### 5.15.2 Federal Risk and Authorization Management Program

{% hint style="info" %}
The Federal Risk and Authorization Management Program (FedRAMP) provides a standardized security-assessment and authorization approach for cloud services used by federal agencies.
{% endhint %}

### 5.15.3 Cloud Service Provider Responsibility Versus Customer Responsibility

{% hint style="info" %}
Cloud providers may secure underlying infrastructure while customers remain responsible for users, roles, service principals, secrets, Conditional Access, federation, privileged access, and tenant configuration.
{% endhint %}

### 5.15.4 Identity as a Shared-Responsibility Boundary

{% hint style="info" %}
Misconfigured cloud identity can compromise a federal workload even when the underlying cloud infrastructure operates securely.
{% endhint %}
