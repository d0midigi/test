# 5.16 Department of Defense Cloud Governance

## 5.16 Department of Defense Cloud Governance

### 5.16.1 DoD Cloud Computing Security Requirements Guide

{% hint style="info" %}
The Department of Defense Cloud Computing Security Requirements Guide establishes security requirements for cloud services supporting Department of Defense information.
{% endhint %}

### 5.16.2 Impact Levels

{% hint style="info" %}
DoD cloud Impact Levels (ILs) establish progressively different requirements according to the sensitivity, mission use, and protection requirements of hosted information and services.
{% endhint %}

### 5.16.3 Identity Requirements Across Impact Levels

{% hint style="info" %}
Authentication, federation, privileged administration, cryptography, monitoring, and access control must align with the requirements of the target cloud environment.
{% endhint %}

### 5.16.4 Government Cloud Boundaries

{% hint style="info" %}
Commercial cloud, Government Community Cloud, Government Community Cloud High, Department of Defense cloud environments, and other sovereign or restricted offerings should not be treated as interchangeable identity-security boundaries.
{% endhint %}

### 5.16.5 Hybrid Identity Is Part of Cloud Authorization

{% hint style="info" %}
On-premises Active Directory, Microsoft Entra ID, federation, synchronization, privileged administration, and cloud workloads must be assessed as a connected trust system when one depends upon the other.
{% endhint %}
