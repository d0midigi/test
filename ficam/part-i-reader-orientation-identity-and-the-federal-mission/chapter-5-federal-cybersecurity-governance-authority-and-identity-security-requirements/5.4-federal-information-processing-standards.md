# 5.4 Federal Information Processing Standards

## 5.4 Federal Information Processing Standards

### 5.4.1 The Role of Federal Information Processing Standards

{% hint style="info" %}
Federal Information Processing Standards (FIPS) provide mandatory standards for specific federal information-processing and security functions where applicable.
{% endhint %}

### 5.4.2 FIPS 199

{% hint style="info" %}
FIPS 199 provides a framework for categorizing information systems according to the potential impact of losing confidentiality, integrity, or availability.
{% endhint %}

### 5.4.3 Identity Infrastructure and Security Categorization

{% hint style="info" %}
The impact level of a mission system influences the assurance expected from the identity services upon which that system depends.
{% endhint %}

### 5.4.4 FIPS 200

{% hint style="info" %}
FIPS 200 establishes minimum security requirements for federal information and information systems and connects system categorization to security-control selection.
{% endhint %}

### 5.4.5 FIPS 201

{% hint style="info" %}
FIPS 201 defines requirements for Personal Identity Verification (PIV) credentials and remains central to high-assurance federal identity.
{% endhint %}

### 5.4.6 FIPS 140 Cryptographic Validation

{% hint style="info" %}
FIPS 140 requirements influence cryptographic modules used in identity systems, including Hardware Security Modules (HSMs), smart cards, certificate authorities, authentication devices, and other cryptographic components.
{% endhint %}
