# 5.14 Cybersecurity and Infrastructure Security Agency

## 5.14 Cybersecurity and Infrastructure Security Agency

### 5.14.1 CISA's Federal Cybersecurity Role

{% hint style="info" %}
The Cybersecurity and Infrastructure Security Agency (CISA) provides operational cybersecurity direction, services, guidance, threat information, and capabilities across the federal civilian enterprise.
{% endhint %}

### 5.14.2 Binding Operational Directives

{% hint style="info" %}
Binding Operational Directives can require federal civilian agencies to take specific cybersecurity actions when significant risks affect the federal enterprise.
{% endhint %}

### 5.14.3 Known Exploited Vulnerabilities Catalog

{% hint style="info" %}
The Known Exploited Vulnerabilities (KEV) Catalog provides a prioritized set of vulnerabilities associated with observed exploitation and can influence remediation urgency.
{% endhint %}

### 5.14.4 Continuous Diagnostics and Mitigation

{% hint style="info" %}
Continuous Diagnostics and Mitigation (CDM) supports visibility into assets, vulnerabilities, identities, access, and security posture across participating federal agencies.
{% endhint %}

### 5.14.5 CISA Zero Trust Maturity

{% hint style="info" %}
CISA's Zero Trust guidance helps agencies evaluate progress across identity, devices, networks, applications and workloads, and data.
{% endhint %}

### 5.14.6 Federal Civilian Identity Security

{% hint style="info" %}
CISA guidance increasingly emphasizes phishing-resistant multifactor authentication, identity governance, privileged access, visibility, and modernization of authentication infrastructure.
{% endhint %}
