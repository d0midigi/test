# 5.17 Defense Industrial Base and Contractor Identity Governance

## 5.17 Defense Industrial Base and Contractor Identity Governance

### 5.17.1 The Defense Industrial Base

{% hint style="info" %}
The Defense Industrial Base (DIB) includes contractors and supporting entities that process, store, transmit, develop, or support information and capabilities associated with Department of Defense missions.
{% endhint %}

### 5.17.2 Contractor Identity Can Become Mission Identity

{% hint style="info" %}
Contractor accounts, administrative access, federation, service identities, and cloud access may interact directly with government resources.
{% endhint %}

### 5.17.3 Controlled Unclassified Information Responsibilities

{% hint style="info" %}
Contractor environments handling CUI must implement required safeguards and appropriately govern identities that can reach protected information.
{% endhint %}

### 5.17.4 Cybersecurity Maturity Model Certification

{% hint style="info" %}
Cybersecurity Maturity Model Certification (CMMC) provides an assessment mechanism for evaluating implementation of required cybersecurity practices within applicable Defense Industrial Base environments.
{% endhint %}

### 5.17.5 Contractor Access Must Remain Governed

{% hint style="info" %}
Contract expiration, role changes, sponsor changes, separation, access recertification, and privileged-account ownership must propagate into identity lifecycle processes.
{% endhint %}

### 5.17.6 Supply-Chain Identity Risk

{% hint style="info" %}
Third-party administrators, managed-service providers, software vendors, cloud providers, and support personnel can become indirect paths into protected federal identity systems.
{% endhint %}
