# 5.19 Security Controls Versus Security Outcomes

## 5.19 Security Controls Versus Security Outcomes

### 5.19.1 A Control Can Exist Without Achieving Its Purpose

{% hint style="info" %}
A multifactor-authentication requirement may technically exist while legacy authentication, emergency exclusions, insecure federation, session theft, or alternative credential paths bypass it.
{% endhint %}

### 5.19.2 Least Privilege Must Be Evaluated Through Effective Authority

{% hint style="info" %}
Reviewing direct group membership alone cannot prove least privilege when delegated rights, nested groups, local administration, certificate enrollment, service identities, or cloud permissions create additional authority.
{% endhint %}

### 5.19.3 Audit Logging Must Produce Useful Evidence

{% hint style="info" %}
Enabling a policy does not guarantee that required events are generated, centrally collected, retained, correlated, or reviewed.
{% endhint %}

### 5.19.4 Network Segmentation Must Restrict Meaningful Paths

{% hint style="info" %}
A firewall rule is useful only when it actually constrains the administrative, authentication, or lateral-movement pathway the control is intended to reduce.
{% endhint %}

### 5.19.5 Identity Governance Must Affect Real Access

{% hint style="info" %}
A recertification process that approves outdated entitlements without challenging their necessity satisfies procedure more readily than security.
{% endhint %}
