# 5.8 Federal Identity, Credential, and Access Management Governance

## 5.8 Federal Identity, Credential, and Access Management Governance

### 5.8.1 FICAM as the Federal Identity Discipline

{% hint style="info" %}
Federal Identity, Credential, and Access Management (FICAM) provides an architectural and governance approach for managing identities, credentials, access, federation, and lifecycle processes across federal systems.
{% endhint %}

### 5.8.2 Identity Begins Before the Account

{% hint style="info" %}
FICAM separates the underlying identity from the individual account representations that may exist across applications, directories, clouds, and partner systems.
{% endhint %}

### 5.8.3 Credentialing Is Not the Same as Authentication

{% hint style="info" %}
Credential issuance establishes an authenticator relationship; authentication occurs when that authenticator is subsequently used to prove identity.
{% endhint %}

### 5.8.4 Authentication Is Not Authorization

{% hint style="info" %}
Successful authentication establishes an identity context, while authorization determines what the authenticated principal may access or perform.
{% endhint %}

### 5.8.5 Federation Is Governed Trust

{% hint style="info" %}
Federation transfers an identity decision between authorities but does not eliminate the need to govern claims, assurance, scope, authorization, and revocation.
{% endhint %}

### 5.8.6 Identity Lifecycle Is a Governance Function

{% hint style="info" %}
Provisioning, modification, recertification, credential replacement, suspension, revocation, and deprovisioning are part of the security model rather than administrative housekeeping.
{% endhint %}
