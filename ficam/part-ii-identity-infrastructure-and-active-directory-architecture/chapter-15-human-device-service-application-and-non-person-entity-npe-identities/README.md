# Chapter 15 — Human, Device, Service, Application, and Non-Person Entity (NPE) Identities

### Abstract

Identity security changes according to what an identity represents. Human users, privileged administrators, contractors, computers, services, applications, automation, and workloads differ in ownership, authentication, lifecycle, privilege, observability, and failure modes. This chapter examines Person Entities and Non-Person Entities across Active Directory, Microsoft Entra ID, hybrid environments, and federal Identity, Credential, and Access Management architectures. Particular attention is given to human accounts, computer identities, service accounts, managed service accounts, application objects, service principals, managed identities, workload federation, device registration, authoritative attributes, sponsorship, ownership, synchronization, and identity correlation. Offensive analysis examines stale identities, orphaned service accounts, machine-account abuse, overprivileged applications, hidden ownership relationships, identity collisions, and NPE persistence. Defensive analysis emphasizes inventory, attribution, lifecycle enforcement, privilege boundaries, telemetry, recertification, and attack-path reduction. The chapter establishes that identity type is not administrative metadata; it materially determines how authority is created, exercised, monitored, compromised, revoked, and restored.
