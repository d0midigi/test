# Chapter 8 - Active Directory Forests, Domains, and the Architecture of Authority

### Abstract

Chapter 8 begins the detailed examination of Active Directory architecture by focusing on forests, domains, trees, Organizational Units (OUs), sites, subnets, naming contexts, namespace, security principals, and administrative boundaries. It explains why the forest represents the primary Active Directory security boundary and why domains, OUs, sites, and network segments should not be mistaken for independent isolation boundaries.

This chapter examines domain Security Identifiers (SIDs), Relative Identifiers (RIDs), Service Principal Names (SPNs), built-in administrative groups, delegated administration, object ownership, inheritance, `AdminSDHolder`, `SDProp`, and the Enterprise Access Model (EAM). Particular attention is given to hidden Tier 0 assets and the difference between logical hierarchy and effective control. Readers are then introduced to graph-based attack-pathway thinking in which users, groups, computers, policies, management platforms, and trust relationships form interconnected nodes and edges. The chapter establishes a model for analyzing Active Directory according to actual administrative reach rather than visible directory structure and prepares the reader to examine how that authority is physically maintained by domain controllers and replication.
