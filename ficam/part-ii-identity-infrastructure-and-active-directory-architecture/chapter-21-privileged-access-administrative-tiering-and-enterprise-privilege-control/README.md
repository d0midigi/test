# Chapter 21 - Privileged Access, Administrative Tiering, and Enterprise Privilege Control

### Abstract

Privileged identities can alter the systems that establish authentication, authorization, configuration, recovery, and trust across an enterprise. This chapter examines how federal and DoD environments should identify, separate, issue, constrain, monitor, and revoke administrative authority across Active Directory, Microsoft Entra ID, endpoints, servers, cloud services, applications, PKI, virtualization, backup, and other Tier 0 dependencies. It covers administrative tiering, privileged access workstations, separate administrative identities, just-in-time and just-enough administration, Microsoft Entra Privileged Identity Management, privileged access management, emergency access, service and automation privilege, credential placement, session control, and administrative-path isolation. Offensive analysis focuses on locating shadow administrators, cross-tier authentication, standing privilege, management-plane dependencies, privileged-session exposure, and paths that convert lesser administrative authority into control of higher-value systems. Defensive analysis emphasizes privilege minimization, clean administrative sources, activation controls, session telemetry, recertification, choke-point reduction, and trusted recovery. The chapter establishes that privilege is not merely membership in an administrative group; it is any capability that can materially influence an identity control plane.
