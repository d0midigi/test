# Chapter 12 - Windows Authentication, Kerberos, NTLM, and Delegation

### Abstract

Chapter 12 explains how Windows proves identity and creates the authenticated security contexts upon which authorization depends. It examines Winlogon, credential providers, LSA, LSASS, Security Support Providers, logon types, computer authentiation, Netlogon secure channels, NTLM, challenge-response authentication, Pass-the-Hash, NTLM relay, and NTLM reduction. The Kerberos authentication protocol is explored in depth through the Key Distribution Center (KDC), `krbtgt`, AS and TGS exchanges, pre-authentication, TGTs, service tickets, SPNs, Kerberoasting, encryption types, the Privilege Attribute Certificate (PAC), Pass-the-Ticket, ticket forgery, referrals, and cross-domain authentication. Delegation receives substantial treatment through unconstrained delegation, constrained delegation, protocol transition, S4U, Resource-Based Constrained Delegation (RBCD), and Machine Account Quota. The chapter also addresses Protected Users, Authentication Policies, Authentication Policy Silos, Kerberos armoring, compound authentication, PKINIT, PIV/CAC integration, Windows Hello for Business, authentication telemetry, and credential recovery. Authentication is presented as both a protocol function and a transferable source of authority.
