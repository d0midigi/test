      <center>   <h1>Active Directory A-Z Attack Notes</h1></center><br>
      <p>Understanding the full spectrum that comprises the security landscape of Active Directory is essential for maintaining a strong and resilient enterprise defense security posture against the myriad of attacks that plague this directory infrastructure. This list highlights many of the most popular and commonly used security vulnerabilities and conceptual risks that organizations seek to monitor to protect their identity infrastructure.</p><br>
      <p>Select a letter tab on the left to view specific Active Directory threat vectors, exploit pathways, and definitions.</p>
    </div>

    <div id="panel-a" class="panel" role="tabpanel" tabindex="0">
      <h2 style="text-align: center;"><span style="color: #fe2c5a;">ACTIVE DIRECTORY ATTACKS STARTING WITH THE LETTER 'A'</span></h2>
<p style="text-align: center;">&bull;&bull;&bull;</p>
<ul>
<li>
<h4>ACCESS CONTROL LIST / ACCESS CONTROL ENTRY (ACL/ACE)-BASED ATTACKS</h4>
<p>Attackers target weak Active Directory Object Access Control Lists (ACLs) to gain control over high-value objects. A common vector is abusing <code>GenericAll</code>, <code>GenericWrite</code>, or <code>WriteDacl</code> permissions over a user or group. If an attacker controls an account with <code>WriteDacl</code> over a target object (like a Domain Admin or a targeted user), they can modify Access Control Entries (ACEs) to grant themselves explicit full control (<code>GenericAll</code>) or force a password reset.</p>
</li><br>
<li style="text-align: left;">
<h4><span style="color: #000000;">ATTACKER 
  
  <ul><li style="text-align: left;">
<h4><span style="color: #000000;">ATTACK DEMONSTRATION<br /></span></h4>
      <div class="code-block">
  <pre><code>&gt;# Import PowerView module
Import-Module .\PowerView.ps1

# Add GenericAll rights for the compromised account (e.g., "evil_user") over the target account (e.g., "target_admin")

Add-DomainObjectAcl -TargetIdentity "target_admin" -PrincipalIdentity "evil_user" -Rights GenericAll -Verbose
</code></pre></div>
  <p style="text-align: center;">&bull;&bull;&bull;</p>
<li style="text-align: left;">
<h4><span style="color: #000000;">DEFENDER PERSPECTIVE<br /></span></h4>
  <p>Defending against ACL attacks requires two layers:  <em>Detection</em> (monitoring changes to high-value ACLs) and <em>Remediation</em> (auditing and fixing weak permissions, especially tracking objects whose <code>adminCount</code> attribute is set to <code>'1'</code> via the AdminSDHolder process).</p><br>
  <li style="text-align: left;">
<h4><span style="color: #000000;">DETECTION STRATEGY (KQL / MICROSOFT SENTINEL) DEMONSTRATION<br /></span></h4>
    <p>To catch this, monitor Event ID 4662 (<em>An operation was performed on an object</em>) on Domain Controllers. Look for modifications (<code>WriteDacl</code> access) targeting sensitive object classes where the performing user is not a standard administrative account.</p><br>
    <div class="code-block">
  <pre><code>&gt;SecurityEvent
  | where EventID == 4662
  | extend ObjectProperties = parse_xml(EventData)
| extend ObjectType = tostring(ObjectProperties.EventData.Data.[0])

| extend AccessMask = tostring(ObjectProperties.EventData.Data.[3])
| extend AccountName = tostring(ObjectProperties.EventData.Data.[1])
| where AccessMask in~ ("0x40000", "0x100") // WriteDacl or Control Access

| where ObjectProperties.EventData.Data.[5] contains "bf967a86-0de6-11d0-a285-00aa003049e2" // GUID for User Object Class
| project TimeGenerated, AccountName, ObjectProperties.EventData.Data.[4], AccessMask
</code></pre></div>
  <p style="text-align: center;">&bull;&bull;&bull;</p>
 <li style="text-align: left;">
<h4><span style="color: #000000;">REMEDIATION SNIPPET (ACTIVE DIRECTORY HARDENING)<br /></span></h4>
   <p>This defensive PowerShell script automates the detection of non-default, dangerous ACL modifications (like <code>GenericAll</code> or <code>WriteDacl</code>) applied to Organizational Units (OUs) or users by scanning for explicit permissions assigned to low-privileged groups.</p><br>
   <div class="code-block">
  <pre><code>&gt;# Query ACLs for a specific sensitive OU to find non-standard explicit allows
$TargetOU = "OU=Privileged Users,DC=domain,DC=local"
(Get-Acl -Path "AD:\$TargetOU").Access | Where-Object {
    $_.IsInherited -eq $false -and 
    ($_.ActiveDirectoryRights -match "GenericAll" -or $_.ActiveDirectoryRights -match "WriteDacl") -and
    $_.IdentityReference -notmatch "Domain Admins|Enterprise Admins|SYSTEM"
} | Select-Object IdentityReference, ActiveDirectoryRights, AccessControlType
</code></pre></div>
  <p style="text-align: center;">&bull;&bull;&bull;</p>
 
        
        
        <li><strong>Active Directory Certificate Services (AD CS) Relay (ESC8)</strong><br>
          In an ESC8 attack, an attacker forces a domain-joined machine (often a Domain Controller via the MS-EFSR PetitPotam protocol) to authenticate against another domain-joined machine they control via NTLM. The attacker then relays this NTLM authentication session to an unauthenticated HTTP Web Enrollment endpoint hosted by Active Directory Certificate Services (AD CS). Because the endpoint allows NTLM authentication and converts it into an X.509 certificate enrollment request, the attacker successfully requests a client authentication certificate impersonating the victim machine, granting them full domain compromise.</li><br>
  <li style="text-align: left;">
<h4><span style="color: #000000;">ATTACKER PERSPECTIVE<br /></span></h4>
<p>An attacker is essentially looking to conduct a Man-in-the-Middle (MitM) and NTLM relay exploit attack that targets Active Directory Certificate Services (AD CS) to achieve instant, silent domain dominance. It bypasses the need for misconfigured certificate templates.</p>
        <li><strong>Active Directory Federation Services (AD FS) Signing Key Theft</strong><br>
Stealing the private token-signing certificate from an Active Directory Federation Services (AD FS) server to forge SAML assertions and access cloud resources.</li><br>
        <li><strong>AdminSDHolder DACL (Discretionary Access Control List) Tampering</strong><br>
Directly modifying the Discretionary Access Control List (DACL) of the AdminSDHolder container to introduce silent, persistent administrative permissions.</li><br>
        <li><strong>AdminSDHolder Exploitation</strong><br>
Injecting a malicious account into the AdminSDHolder object's ACL, causing Active Directory to automatically push persistent administrative privileges to that account every 60 minutes.</li><br>
        <li><strong><code>AdFind</code> Automated Reconnaissance</strong><br>
          Utilizing the popular command-line utility <code>AdFind</code> to execute broad, unstructured queries that quickly pull extensive lists of users, groups, and domain trusts.</li><br>
        <li><strong><code>ADPrep</code> Vulnerability Exploitation</strong><br>
Target-hunting for legacy schema extensions or old installation artifacts from previous Active Directory upgrades to exploit known privilege management flaws.</li><br>
        <li><strong>Anonymous Lightweight Directory Access Protocol (LDAP) Binding</strong><br>
Querying an unhardened Domain Controller without any authentication credentials to fully enumerate domain users, groups, and system structures.</li><br>
        <li><strong>AS-REP Roasting</strong><br>
Targeting domain accounts that do not require Kerberos pre-authentication. An attacker requests a Kerberos authentication ticket (AS-REP) for those accounts without knowing their original plaintext passwords, receiving an encrypted packet that they can crack offline to harvest the plaintext credential.</li><br>
        <li><strong>Authentication Pre-Authentication Risks</strong><br>
          Monitoring accounts that do not require Kerberos pre-authentication as these can be targeted for offline analysis if service responses are intercepted.</li><br>
        <li><strong>Authentication Silo Bypass</strong><br>
Finding gaps or unassigned systems outside an active Authentication Policy Silo to bypass strict credential restrictions applied to high-privileged accounts.</li><br>
        <li><strong>Azure AD Connect Account Hijacking</strong><br>
          Target-hunting the specific <code>MSOL_</code> on-premises account used by synchronization engines to exploit its high replication privileges.</li><br>
        <li><strong>Azure AD Connect Password Sync Extraction</strong><br>
Extracting the decryption key and credentials used by Azure AD Connect synchronization accounts to sync on-premises AD hashes to Entra ID.</li>
      </ul>

      <h2>Active Directory Attacks Starting with the Letter 'B'<center><h4 style="color: #000000;">&bull;&bull;&bull;</center>
</h2>
      <ul>
        <li><strong>Backup <code>NTDS.dit</code> Theft</strong><br>
Locating and copying poorly secured backup files or disaster recovery images of Domain Controllers to extract the primary AD credential database.</li><br>
        <li><strong>Backup Operators Abuse</strong><br>
          Leveraging membership in the Backup Operators group to read sensitive system files, including the <code>NTDS.dit</code> database.</li><br>
        <li><strong>Backup Operators Domain Hijacking</strong><br>
Abusing members of the Backup Operators group to read sensitive system files or replace registry hives on a Domain Controller.</li><br>
        <li><strong>BitLocker Key Extraction from Active Directory (AD)</strong><br>
          Querying the <code>msFVE-RecoveryInformation</code> directory attribute to steal stored BitLocker volume recovery keys for domain-joined endpoints.</li><br>
<li><strong>BitLocker Recovery Password Harvesting via Lightweight Directory Access Protocol (LDAP)</strong><br>
Executing unmonitored LDAP queries to pull full plaintext drive-encryption keys stored in computer object attributes.</li><br>
        <li><strong>BloodHound Path Exploitation</strong><br>
          Utilizing graph theory toolsets to automatically discover and execute complex, nested privilege escalation pathways.</li><br>
        <li><strong>Brute-Force Attack on Kerberos Pre-Authentication</strong><br>
Bombarding the Kerberos service with guesses specifically for accounts that do not require pre-authentication, collecting response packages to crack offline.</li><br>
        <li><strong>Built-In Group Exploitation</strong><br>
Target-hunting for unmonitored default groups, such as Account Operators, Print Operators, or Backup Operators that hold unexpected local or domain-wide administrative permissions.</li><br>
        <li><strong>Bypass User Access Control (UAC)</strong><br>
Executing specific administrative tasks on domain-joined machines by pivoting through misconfigured system files or high-integrity processes to execute unauthorized code.</li><br>
        <li><strong>Bypassing AppLocker via Active Directory</strong><br>
          Utilizing misconfigured Active Directory Group Policy Objects (GPOs) to run unauthorized administrative tools on domain-joined workstations.</li>
</ul>

</li><br>

    <div id="panel-d" class="panel" role="tabpanel" tabindex="0">
  <h2>Active Directory Attacks Starting with the Letter 'D'<center><h4 style="color: #000000;">&bull;&bull;&bull;</center></h2>
      <ul><li><strong>DCShadow</strong><br> Registering a rogue system as a temporary Domain Controller in Active Directory memory, an attacker with administrative privileges can inject malicious configuration changes such as implementing backdoor credentials or modify group memberships - directly into the enterprise replication stream, completely bypassing standard security event logging mechanisms.
</li><br>
        <li><strong> DCSync</strong><br>
          Simulating the behaviors of a Domain Controller using the Directory Replication Service Remote Protocol (MS-DRSR) to request password hashes directly from the domain.</li><br>
        <li><strong> Default Password Spraying</strong><br>
          Testing common corporate credentials, such as `Welcome123!` across all discovered domain accounts simultaneously to bypass individual account lockout thresholds.</li><br>
        <li><strong> Diamond Ticket Attack</strong><br>
          Using the <code> krbtgt</code> account's long-term key to decrypt a valid Ticket Granting Ticket (TGT), attacker modify its contents (such as adding high-privileged group SIDs) and then re-encrypt it. Because the attacker requests a legitimate TGT from the Domain Controller first and only alters the existing ticket, the final forged credential bypasses many common detection rules that scan for anomalous or missing ticket properties.</li><br>
        <li><strong>Directory Services Restore Mode (DSRM) Account Abuse</strong><br>
          Extracting the local administrator password hash of the DSRM account on a DC, then using it to gain persistent, alternative domain control via Pass-the-Hash (PtH).</li><br>
        <li><strong>Directory Services Restore Mode (DSRM) Exploitation</strong><br>
          Using the <code> GetNCChanges</code> request through specialized security tools to mimic a Domain Controller and pull password hashes directly from the domain database <code>(NTDS.dit)</code>.</li><br>
        <li><strong>Directory Services Restore Mode (DSRM) Password Syncing</strong><br>
          Forcing the local Directory Services Restore Mode (DSRM) password to sync with a domain account hash, opening a backdoor via legacy authentication.</li><br>
        <li><strong>Distributed Component Object Model (DCOM) Privilege Escalation</strong><br>
          Executing arbitrary code with <code>SYSTEM</code> privileges on domain-joined assets by abusing Distributed Component Object Model (DCOM) applications that lack proper access controls.</li><br>
        <li><strong>Distributed File System (DFS) Interception</strong><br>
          Setting up unauthorized DFS targets or mimicking name namespaces to intercept and alter software distribution data or administrative files.</li><br>
        <li><strong>Domain Name Service (DNS) Admins Abuse</strong><br>
          Exploiting membership in the <code>DNSAdmins</code> group to force the DNS service on a Domain Controller to execute a malicious Dynamic Link Library (DLL) object at <code>SYSTEM</code>-level.</li><br>
        <li><strong>Domain Name Service (DNS) Zone Scavenging Vulnerabilities</strong><br>
          Manipulating AD-integrated DNS zones through insecure dynamic updates to hijack internal traffic, intercept authentication attempts, or conduct man-in-the-middle attacks.</li><br>
        <li><strong>Dynamic DNS Poisoning via Dynamic Host Configuration Protocol (DHCP)</strong><br>
          Forcing unauthenticated name changes on internal servers through a compromised DHCP server to alter the domain's central name resolution path.</li>
      </ul>
    </div>

      <div id="panel-e" class="panel" role="tabpanel" tabindex="0"><h2>Active Directory Attacks Starting with the Letter 'E'<center><h4 style="color: #000000;">&bull;&bull;&bull;</center></h2>
      <ul>
        <li><strong>Encrypted Group Policy Object (GPO) Password Scavenging</strong><br>
          Searching custom scripts or older Group Policy configurations for hardcoded passwords that were encrypted with known, public static keys.</li><br>
        <li><strong>Endpoint Detection and Response (EDR) Policy Deactivation via GPO</strong><br>
          Pushing unauthorized registry changes via domain Group Policy Objects (GPOs) to explicitly disable endpoint detection software across all domain-joined workstations.</li><br>
        <li><strong>Edge-Device Password Invalidation</strong><br>
          Attacking internet-facing domain authentication points (like AD FS) with targeted credential sprays to rapidly disable production accounts through internal lockouts.</li><br>
        <li><strong>Enterprise Admins Hijacking</strong><br>
          Targeting specific cross-forest configurations to compromise parent forest structures from a compromised child domain.</li><br>
        <li><strong>Enterprise Admin Token Theft</strong><br>
          Monitoring active sessions across a domain to steal the access tokens of Enterprise Administrators who interact with compromised low-tier servers.</li><br>
        <li><strong>Entra ID / Azure AD Hybrid Identity Pivot</strong><br>
          Moving laterally from a compromised on-premises AD environment up into a connected cloud tenant by abusing synchronization service permissions.</li><br>
        <li><strong>Entra ID Seamless Single Sign-On (SSO) Extraction</strong><br>
          Extracting the decryption keys for the <code> AZUREADSSOACC</code> computer account to forge authentication cookies for cloud Single Sign-On (cSSO).</li><br>
        <li><strong>Enumeration via Lightweight Directory Access Protocol (LDAP)</strong><br>
          Conducting systematic, unauthorized directory mapping using unauthenticated or low-privileged LDAP queries to find high-value targets within a forest domain structure.</li><br>
        <li><strong>ESC1 to ESC13 (Active Directory Certificate Services (AD CS) Flaws)</strong><br>
          Exploiting misconfigured certificate templates (such as allowing <code>SAN</code> (Subject Attribute Name) specification or domain client authentication) to escalate privileges.</li><br>
        <li><strong>Event Log Clearing</strong><br>
          Programmatically deleting Security or System event logs on Domain Controllers to erase administrative audit trails and hinder forensic investigations.</li></ul>

    <div id="panel-f" class="panel" role="tabpanel" tabindex="0"><h2>Active Directory Attacks Starting with the Letter 'F'<center><h4 style="color: #000000;">&bull;&bull;&bull;</center></h2>
      <ul>
        <li><strong>File Classification Infrastructure (FCI) Data Harvesting</strong><br>
Intercepting or abusing Microsoft's automated data classification scripts on domain file servers to discover and steal highly confidential corporate records.</li><br>
        <li><strong>File Sharing Credential Hunting</strong><br>
          Scanning open <code> SYSVOL</code>, <code> NETLOGON</code>, or departmental network file shares for configuration files, scripts, and documentation containing hardcoded domain credentials.</li><br>
        <li><strong>Fine-Grained Password Policy (FGPP) Enumeration</strong><br>
Querying the Password Settings Containers (PSC) inside AD to determine which high-value groups have weak password complexity thresholds.</li><br>
        <li><strong>Fine-Grained Password Policy (FGPP) Overrides</strong><br>
Injecting specific, weak Password Settings Objects (PSOs) directly into targeted high-value user objects to circumvent global domain password strength requirements.</li><br>
        <li><strong>Flexible Single Master Operation (FSMO) Role Targeting</strong><br>
Targeting the specific Domain Controllers holding unique FSMO roles (like the PDC Emulator) to disrupt authentication or execute targeted time-sync attacks.</li><br>
        <li><strong>Foreign Security Principals (FSP) Abuse</strong><br>
Exploiting trust boundaries by adding malicious users from an external or untrusted forest directly into groups within the target forest.</li><br>
        <li><strong>Foreign Security Principal (FSP) Escalation</strong><br>
Injecting a malicious object from an unmonitored external domain into a highly privileged group within the trusted targeted domain.</li><br>
        <li><strong>Forest-Trust Blind Spots</strong><br>
          Leveraging historical NTLM fallback mechanisms across selective cross-forest trusts to access unauthorized shared resources.<li></ul>

    <div id="panel-g" class="panel" role="tabpanel" tabindex="0"><h2>Active Directory Attacks Starting with the Letter 'G'<center><h4 style="color: #000000;">&bull;&bull;&bull;</center></h2>
      <ul>
        <li><strong>Global Catalog (GC) Data Harvesting</strong><br>
Querying specific Global Catalog ports (3268/3269) to bypass typical domain-level monitoring and quietly extract forest-wide user information.</li><br>
        <li><strong>Global Catalog (GC) Pass-the-Hash (PtH)</strong><br>
Using a stolen user account hash to authenticate against Global Catalog ports across a multi-domain forest to pull universal group configurations.</li><br>
        <li><strong>Golden Certificate Attack</strong><br>
Stealing the private key of an Active Directory Certificate Services (AD CS) CA certificate to forge arbitrary authentication certificates valid for any user indefinitely.</li><br>
        <li><strong>Group Policy Object (GPO) Container Deletion</strong><br>
Deleting or replacing the Active Directory container reference for a critical GPO to immediately disable host defenses across the enterprise.</li><br>
        <li><strong>Group Policy Object (GPO) Permissions Hijacking</strong><br>
Editing the access controls of an existing Group Policy Object (GPO) to push malicious scripts, scheduled tasks, or local administrator additions to all linked domain machines.</li><br>
        <li><strong>Group Policy Object (GPO) Script Modification Persistence</strong><br>
Overwriting structural startup or shutdown scripts inside the SYSVOL file structure to ensure malicious code runs with <code> SYSTEM</code>-level rights at boot time.</li><br>
        <li><strong>Group Policy Object (GPO) Symbolic Link Exploitation</strong><br>
Creating symbolic links inside a GPO share directory to force client machines into modifying local system files during policy updates.</li><br>
        <li><strong>Group Policy Preference (GPP) Password Decryption</strong><br>
          Finding legacy Group Policy Preference (GPP) XML files containing encrypted passwords (known as '<code>cpassword</code>') and decrypting them using standard static AES keys.</li>      </ul>

    <div id="panel-h" class="panel" role="tabpanel" tabindex="0"><h2>Active Directory Attacks Starting with the Letter 'H'<center><h4 style="color: #000000;">&bull;&bull;&bull;</center></h2>
      <ul>
        <li><strong>Hash Cracking (Offline)</strong><br>
Using brute-force cluster tools like Hashcat to crack stolen NTLM or Kerberos TGS/TGT hashes retrieved from an AD database or network capture.</li><br>
        <li><strong>Heuristics Mapping (BloodHound Recon)</strong><br>
          Mass-harvesting session data and session data properties to identify logons of highly-privileged users using weak hosts.</li><br>
        <li><strong>Honeytoken Evasion</strong><br>
Analyzing structural domain metadata like creation dates of Active Directory accounts (in an unauthorized manner) to actively avoid triggering deceptive defender trap (honey) accounts.</li><br>
        <li><strong>Honeytoken Triggering</strong><br>
Identifying and probing deceptive AD objects placed by defenders, inadvertently alerting security teams to active reconnaissance or lateral movement.</li><br>
