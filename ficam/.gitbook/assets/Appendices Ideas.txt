Appendices Ideas

1. Essential Reference Appendices
- Active Directory Port Reference: A cheat sheet listing necessary ports (e.g., TCP/UDP 53 for DNS, 88 for Kerberos, 389/636 for LDAP/LDAPS, and RPC dynamic ports). This is critical for configuring firewalls, routing, isolating, and segmenting Active Directory domains and networks.

2. Default FSMO Roles Quick Reference: A breakdown of the five FSMO roles, their locations, and how to transfer/seize them.

3. AD Object & Attribute Dictionary: A lookup of primary AD objects (Users, Computers, Groups, OUs) and essential attributes (UserPrincipalName, sAMAccountName, ObjectGUID).

4. Privileged Groups & Tiering Reference: A list of built-in privileged groups, including DA, EA, and SAs, along with guidelines on restricting their memberships per Tier 0 guidelines.

5. Administrative Delegation (ACLs) Mapping: Concrete guidance on granting the right permissions to the right accounts, avoiding overly broad access, and implementing PoLP.

AD DEPLOYMENT & DESIGN APPENDICES

6. AD Limits & Scalability Specifications: A cheat sheet based on official Microsoft specifications, including the maximum number of objects per domain (typically 2.15 billion) and RID pool size capacities.

7. Forest & Domain Functional Levels: A compatibility chart showing which Windows Server operating systems support which Active Directory functional levels.

POWERSHELL & AUDITING APPENDICES

8. Active Directory PowerShell cmdlet Cheat Sheet: Frequently used PowerShell commands to bulk-create objects, query trust relationships, and export directory data.

9. Event ID Monitoring Catalog: A targeted list of Windows Event IDs that IT/Security teams should monitor for Active Directory health and compromise.

AD TROUBLESHOOTING & COMPLIANCE APPENDICES

10. Disaster Recovery & AD Restore Procedures: Step-by-step instructions for performing authoritative and non-authoritative restores of Active Directory Domain Services (AD DS).

11. Active Directory Hardening Checklist: An actionable checklist based on Microsoft Security Best Practices or DISA STIGs for protecting the AD domain and network.

AD CORE ADMINISTRATION & REFERENCES APPENDICES

12. Active Directory Refresher - Quick Notes: A high-level, condensed summary of core AD concepts (e.g., Forests, Domains, Trusts, Global Catalog, OUs, and Group Policy). It serves as a rapid primer for readers who need a baseline refresher before diving into advanced topics.

13. Active Directory Key Attributes Cheat Sheet: A quick- lookup dictionary mapping of critical object attributes (like sAMAccountName, userPrincipalName, ObjectSID, memberOf, and pwdLastSet). This is essential for writing accurate filters and scripts.

14. Event Log Reference Guide: A broad catalog explaining how Windows handles event logging architecture, covering log sizes, rollover behaviors, and how to properly configure centralized log forwarding (SIEM/WEF) for domain controllers.

15. NIST SP Documentation Index - Key Standards for Active Directory: A curated directory pointing readers to exact sections of NIST Special Publications (like NIST SP 800-53, 800-63, and 800-207) that mandate specific configuration baselines for identity systems.

POWERSHELL & AUTOMATION SCRIPTS & COMMANDS APPENDICES

16. Must-Have PowerShell Commands to Check for DNS and LDAP Domain Enumeration: A targeted script library defenders can use to spot and/or detect unauthorized enumeration on the domain directed toward LDAP and Active Directory-integrated DNS.

17. PowerShell One-Liners Collection: A practical library of copy-and-paste commands with explanations used to perform rapid operational tasks, such as finding locked-out users, listing empty groups, or identifying inactive computer accounts. 

18. PowerShell-Based Registry Execution Cheat Sheet: A technical guide detailing how to use PowerShell to query or modify specific registry paths on endpoints or domain controllers, often used to enforce security baselines or detect unauthorized registry persistence.

DEFENSIVE ENGINEERING & HARDENING APPENDICES

19. The Defender's Master-Class List of Active Directory Key Event IDs: A highly specific security catalog mapping critical security Event IDs (such as 4720 for user creation, 4728 for privileged group changes, or 4624 for logons) to detect near-real-time indicators of compromise.

20. Active Directory Certificate Services (AD CS) Security Checklist: A specialized security auditing list focused on hardening Public Key Infrastructure (PKI) against common misconfigurations, such as overly permissive certificate templates (ESC1–ESC8).

21. YARA Detection Rule Template: Pre-authored code templates used by security systems to scan memory or files for known AD attack tools, allowing defenders to deploy immediate detection capabilities. 

22. Technical Verification Checklist: A step-by-step technical audit guide used by engineers to manually verify that security controls (like SMB signing, LDAP signing, and credential guard) are active and functioning correctly.

OFFENSIVE SECURITY, TOOLING & ETHICAL HACKING APPENDICES

23. Active Directory Offensive and Defensive Tool Arsenal: A comprehensive directory listing industry-standard tools (e.g., Mimikatz, Impacket, BloodHound, PingCastle) alongside a description of what they do and whether they are used to attack or defend.

24. BloodHound Installation Guide: A practical installation walkthrough detailing how to set up the Neo4j database and BloodHound interface to map out and analyze complex attack paths within an Active Directory environment.

25. Hashcat and Kerberos Modes Reference: A syntax cheat sheet listing the exact command codes (like mode 18200 for AS-REP Roasting or mode 13100 for Kerberoasting) used to crack intercepted Active Directory authentication tickets.

26. Cheat Sheets for Common Commands and Defensive Checks: A dual-purpose reference guide mapping offensive commands (like net user /domain) directly to the corresponding defensive commands or logs needed to check if that action took place.

27. Command Explanations and Attacker Rationale Reference: A deep-dive translation matrix that explains why an attacker runs a specific command, what underlying AD vulnerability they are trying to exploit, and what the output tells them.

28. Ethical Hacking Cheat Sheet: A condensed execution playbook for penetration testers and red teams, outlining a standard lifecycle for safely testing an AD environment from initial access to domain dominance.

GOVERNANCE, POLICY & FEDERAL COMPLIANCE APPENDICES

29. AD Security Awareness and Acceptable Use Policy (AUP): A formal template outlining the security responsibilities of domain users and administrators, defining what actions are permitted on organization-owned assets.

30. Important Information Security Mandates, Guidance & Documentation of Importance: A high-level regulatory roadmap summarizing major compliance frameworks (such as FISMA, HIPAA, or ISO 27001) and how they intersect with enterprise identity management.

31. Quick Federal and Military Cyber Policy Reference Chart: A matrix or table mapping operational AD configurations to specific requirements within federal directives, helping military contractors and agency engineers maintain authorization.

32. Security Lists: A consolidated registry of authorized exceptions, critical assets, or restricted software lists required by compliance auditors to verify governance over the domain.

33. Important Federal and Military Issuances: A formal index tracking specific Executive Orders, DoD Instructions (DoDI), and binding operational directives that dictate how federal networks must secure identities and cross-domain solutions.
