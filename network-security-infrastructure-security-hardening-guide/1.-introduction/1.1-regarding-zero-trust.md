# 🤝 1.1 Regarding Zero Trust

The landscape of network security is constantly changing as attackers exploit new vulnerabilities, security features are updated, and new methods of securing devices are discovered. Improper configurations, mishandling of configurations, and weak encryption keys can leave networks vulnerable to cyber threats. All networks are at risk of being compromised, especially if devices are not properly configured and maintained. It is crucial for administrators to play a key role in securing the network against adversarial techniques, requiring dedicated individuals to protect devices, applications, and information.

This guide offers best practices for enhancing overall network security and safeguarding individual network devices. By following these recommendations, you can prevent adversaries from exploiting your network. While the advice provided in this guide is applicable to various types of network devices, we have included sample commands specifically for Cisco Internetwork Operating System (IOS) devices, which can be used to implement recommended security measures.

Regarding **Zero Trust**, it is a security model and system design principle that assumes threats can come from both inside and outside a network's traditional boundaries. Many federal cybersecurity branches, such as that from the NSA, fully support the Zero Trust security model, and many of the recommendations in this guide align with the principles of Zero Trust; however, this guide focuses on mitigating common vulnerabilities in existing networks. System Owners looking to implement more advanced Zero Trust principles may need to adapt the guidance provided here accordingly.
