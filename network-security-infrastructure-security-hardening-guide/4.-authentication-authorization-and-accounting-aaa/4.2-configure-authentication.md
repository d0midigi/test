# 4.2 Configure Authentication

Authentication is a critical process that verifies the identity of individuals or entities accessing network devices. To ensure a secure authentication setup, all devices should prioritize centralized servers for AAA (Authentication, Authorization, and Accounting) services. Local administrator accounts should only serve as a backup authentication method if all centralized servers become unavailable. Similarly, privileged-level authentication should exclusively rely on local passwords as a last resort when centralized servers are inaccessible. This hierarchy prevents adversaries from gaining unauthorized access through local accounts, as access control is primarily governed by AAA servers.

It's recommended to configure centralized authentication for both `login` and privileged (`enable`) access as the primary method using the following configuration commands:

```bash
aaa authentication login default group <GROUP_NAME> local
aaa authentication enable default group <GROUP_NAME> enable
```

By using the `default` keyword, this configuration is globally applied in all instances where an explicit authentication list is not specified. Using a custom named list would require explicit application to each instance using AAA, which could lead to misconfigurations and potential security vulnerabilities.

Replace _`<GROUP_NAME>`_ with the custom name of the AAA server group defined previously, containing the IP addresses of centralized AAA servers and their associated keys.&#x20;

Avoid using the `line` keyword as it does not securely store passwords in the configuration or provide proper accountability.

Never use the `none` keyword as it disables authentication altogether, compromising network security.
