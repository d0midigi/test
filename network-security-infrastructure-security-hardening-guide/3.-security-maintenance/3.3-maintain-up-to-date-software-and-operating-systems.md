# 3.3 Maintain Up-to-Date Software and Operating Systems

Maintaining up-to-date software and operating systems is crucial to mitigate critical vulnerabilities and security risks that can be exploited by adversaries. Outdated operating systems and software expose devices to known vulnerabilities, making them easy targets for attacks.

To ensure network security, it's recommended to upgrade operating systems and software to the latest stable versions provided by the respective vendors. Upgrading may require additional hardware or memory upgrades, and obtaining new software versions may necessitate maintenance or support contracts with the vendors. Some network infrastructure devices may not support auto-update features, requiring a manual requisition and installation process to obtain the latest software from the vendor.
