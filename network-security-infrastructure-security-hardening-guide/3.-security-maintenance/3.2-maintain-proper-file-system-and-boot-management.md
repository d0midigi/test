# 3.2 Maintain Proper File System and Boot Management

Maintaining proper file system and boot management is crucial for ensuring the stability and security of network devices. Network devices typically store configurations in persistent storage and have an active copy running in memory. It's essential to save permanent configuration changes to prevent inconsistencies in configurations after reboots or power loss.

To save configuration changes permanently, you can use the following command:

```plaintext
copy running-config startup-config
```

For temporary changes, it's recommended to insert comments before updated configuration lines, indicating why the change was made and when it should be removed. Comments help maintain clarity and organization in configurations. If the device does not support comments, insert them in a backup copy of the configuration for comparison. Be sure to comment them out as you don't want to affect the entire running config.

Also, as a reminder since we all know better, when copying configurations remotely, use encrypted protocols such as Secure File Transfer Protocol (SFTP) or Secure Copy Protocol (SCP) to ensure data security during transmission. Additionally, secure the backup repository and the copy mechanism to prevent unauthorized access.

Regularly check for unused or unnecessary files on network devices using the following commands:

```plaintext
dir /recursive all-filesystems
delete <PATH:filename>
```

Unused files, especially older operating system files or outdated backup configuration files, should be removed to reduce the attack surface and prevent adversaries from reloading outdated software with known vulnerabilities.

By following these practices, organizations can maintain a clean and secure file system, minimize configuration inconsistencies, and reduce the risk of unauthorized access and potential vulnerabilities.
