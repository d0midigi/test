# 2.4 Utilize Strict Perimeter Access Controls

Network perimeter devices are crucial components in a robust security model and should work in harmony by employing Access Control Lists (ACLs) to manage the flow of incoming and outgoing network traffic. These ACL rulesets should be meticulously configured to explicitly permit only the necessary services and systems that support the network's mission.

Implementing a deny-by-default, permit-by-exception approach, as recommended, involves carefully assessing which connections to allow and then crafting rulesets that focus on permitting only those allowed connections. This strategy enables a single rule to deny multiple types of connections, eliminating the need for separate rules for each blocked connection. Failing to adopt this approach can lead to unnecessary access, thereby increasing the risk of compromise and unauthorized information gathering.

In scenarios where additional perimeter rulesets are required dynamically to prevent adversaries from completing or prolonging an exploit, an Intrusion Prevention System (IPS) is recommended.

Enabling logging on all rulesets that deny or drop network traffic is essential for effective monitoring and incident response. Additionally, logging should be enabled for both successful and unsuccessful attempts to access critical devices by administrators. These logging practices provide valuable insights into network activity, aiding in threat detection, analysis, and response efforts.
