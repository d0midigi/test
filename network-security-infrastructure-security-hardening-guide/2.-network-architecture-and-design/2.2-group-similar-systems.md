# 2.2 Group Similar Systems

Systems within a network should be logically grouped together to prevent adversarial lateral movement from one system to another. Attackers often target easier-to-exploit systems like forgotten printers on a network to gain initial access and then use that foothold to move laterally across the network. Proper network segmentation plays a crucial role in reducing an adversary's ability to exploit different systems on a network.

Implementing network segmentation makes it easier to manage, control, and monitor access restrictions between different types of systems. It's best to isolate similar systems into distinct subnets or Virtual Local Area Networks (VLANs), or physically separate subnets with firewalls or filtering routers. For instance, workstations, servers, printers, telecommunication systems, and other network peripherals should be segregated from each other. Operational technologies, like Industrial Control Systems (ICS), typically require isolation from other information technology and high-risk networks like the Internet.

Physical separation between subnets provides protection because compromising the intermediate device between subnets is necessary for an adversary to bypass access restrictions. To enhance security further, access restrictions should be implemented on internal routers, switches, and firewalls. Only ports and protocols necessary for network operations or valid mission needs should be allowed. Access Control Lists (ACLs) may need duplication and direct application to switches to restrict access between VLANs. Alternatively, they can be applied to core routers where routing occurs between internal subnets. This layered approach to network segmentation and access control significantly strengthens the network's security posture against lateral movements and unauthorized access attempts.
