# 2.5 Implement a Network Access Control (NAC) Solution

To gain internal access to a network, an adversary must breach either the external perimeter or gain access from within. Network Access Control (NAC) solutions play a crucial role in preventing unauthorized physical connections and monitoring authorized ones on a network.

A NAC solution is designed to identify and authenticate unique devices connected to the network. Port security, which is a mechanism often implemented on switches, helps detect unauthorized devices by monitoring a device's media access control (MAC) address.

However, port security can present challenges in management. For instance, it may lead to an increase in support tickets due to valid network ports being blocked, especially in cases where devices frequently change, such as in conference rooms. Additionally, adversaries capable of spoofing a MAC address can bypass port security measures.

A more robust solution is to implement 802.1X, which authenticates devices based on a trusted digital certificate installed on the device. While 802.1X may be more complex to set up due to certificate usage, it offers easier management compared to port security and provides a higher level of assurance in device authentication.
