**Network Basics**

The IEEE (Institute of Electrical and Electronic Engineers) project 802 decided to use Ethernet version 2 as the basis for their CSMA/CD network standard. By enhancing the DEC, Intel and Xerox Ethernet 2 design, they produced the IEEE 802.3 specification, which is now the standard format for Ethernet-based systems and networks.

The name _**“10Base”**_ indicates a signaling speed of 10 million bits per second (bps) with a base band signaling scheme.

* 10BaseT: 10Mbs: Ethernet running over twisted pair cable: 100 meter max.
* 100BaseT: 100Mbs: Ethernet running over twisted pair cable: 100 meter max.

**Other 802.X Standards**

* **802.1:** This group produced an overview of the work of the project and defined the LAN reference model.
* **802.2:** This describes the Logical Link Control services used in all IEEE specified LANs.
* **802.3:** Describes Ethernet-based networks.
* **802.4:** Describes networks using a Token-passing bus.
* **802.5:** Describes networks using a Token-passing ring.
* **802.6:** Specifications for a Metropolitan Area Network (MAN).
* **802.7:** This group advised other working groups on issues relating to broadband transmissions.
* **802.8:** This group is the technical advisory group for FIDDI and fiber optic.
* **802.9:** This group explores integrated data and voice networks.
* **802.11:** Group for wireless Ethernet.

**10BaseT**

10BaseT is also sometimes known as _**twisted pair.**_ A distance of up to 30 meters between the connected devices is the recommended limit.

**TCP/IP Basics – The TCP/IP Protocol**

**TCP/IP Introduction**

TCP/IP, or Transmission Control Protocol/Internet Protocol is the network protocol used for the internet and many local area networks and wide area networks.

Each device is given it’s own Internet Protocol (IP) address typically referred to as the IP Address. IP addresses are assigned either automatically or manually. This IP address is unique to the device and cannot be used by any other device else inside the local network.

A typical IP address might look something like this: 192.168.1.80.

**IP Addresses**

An IP address consists of four, 8bit digits, or _**octets.**_ Being an 8bit value they can only have values between 0 and 255. For convenience, the addresses are written as 4 numbers separated by periods. For example, “192.168.1.80.” A local network, or _**subnet**_ will typically have the first 3 numbers the same.
