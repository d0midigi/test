# Network Operating System and Infrastructure Chapter Contents

Network Operating System and Infrastructure Chapter Contents

_Network Operating System and Infrastructure_ discusses hacking wireless networks; physical security; how to evade IDS and Firewalls; how to detect honey pots; and an introduction to cryptography. In addition, it covers techniques used in hacking Linux, Macintosh, routers, cable modems, firewalls, mobile devices, Bluetooth devices, RFID and USB devices and how to determine security policies for these devices.

**Chapter 1: Hacking Wireless Networks** explores the realm of wireless networking, detailing various wireless standards, SSID configurations, wireless access points, and techniques for cracking WEP among other insights.

**Chapter 2: Physical Security** emphasizes the significance of physical security measures, outlines the challenges faced in securing physical environments, and presents strategies for enhancing the physical security of networks.

**Chapter 3: Evading IDS, Firewalls, and Honeypot Detection** examines the security mechanisms employed by administrators to safeguard networks, including Intrusion Detection Systems (IDS), firewalls, and honeypots, and discusses methods for circumventing these protections.

**Chapter 4: Hacking Routers and Cable Modems** highlights the vulnerabilities inherent in routers and cable modems, which are super important considerations in formulating security policies for both corporate and home environments.

**Chapter 5: Linux Hacking** examines Linux security aspects, covering topics such as rootkits and Intrusion Detection Systems, to provide a comprehensive overview of securing Linux environments.

**Chapter 6: Hacking Mobile Phones, Smartphones, PDAs, and Handheld Devices** addresses the diversity of handheld devices and the vulnerabilities that present useful knowledge for investigators and security professionals alike.

**Chapter 7: Hacking Portable Devices** is divided into three sections focusing on USB, Bluetooth, and RFID devices. It covers attack vectors, security concerns, and countermeasures for each technology, including discussions on RFID-enabled credit card vulnerabilities and protective measures against RFID attacks.

**Chapter 8: Cryptography and Encryption** provides an introduction to cryptography, encryption, and cryptanalysis, detailing various cryptographic attacks and presenting tools for cracking encryption, alongside an overview of RFID security controls.

Chapter Features

Each chapter incorporates numerous educational features tailored to enrich the learning journey of the reader. These features include:

* **Preface**: Provides an overview and sets the stage for the content to come.
* **Chapter Objectives**: Outlines the core concepts and learning goals at the beginning of each chapter, guiding the reader's focus.
* **Key Terms**: Introduces and defines essential terminology used throughout the chapter, aiding in the reader's familiarity with the subject matter.
* **What If? Scenarios**: Presents brief hypothetical situations accompanied by questions, challenging readers to think critically and devise solutions to the problems posed.
* **Chapter Summary**: Offers a concise review of the main ideas discussed in the chapter, reinforcing the reader's understanding of the material covered.
* **Review Questions**: Enables learners to assess their grasp of the chapter content through a series of questions designed to test comprehension.
