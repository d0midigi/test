## 🛠️ Implementation Notes for Both Templates

{% stepper %}
{% step %}
### Use on CodePen

Copy the entire HTML file content and paste into CodePen's HTML panel. No CSS or JS panels needed — it's all self-contained.
{% endstep %}

{% step %}
### Customize colors

Both templates use CSS custom properties (variables) defined in `:root`. Edit the values to change the theme.

```css
:root {
    --accent: #00ff41;        /* Change main accent color */
    --text-primary: #e6edf3;  /* Change text color */
    --bg-primary: #0a0e27;    /* Change background */
}
```
{% endstep %}

{% step %}
### Notes

* Single-file architecture: everything is contained in one HTML file — no build process needed.
* Touch-friendly mobile menu and collapsible sidebar are included.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Browser Compatibility:

* Modern browsers (Chrome, Firefox, Safari, Edge)
* Uses Intersection Observer API (IE11 not supported)
* Graceful degradation for older browsers
{% endhint %}
