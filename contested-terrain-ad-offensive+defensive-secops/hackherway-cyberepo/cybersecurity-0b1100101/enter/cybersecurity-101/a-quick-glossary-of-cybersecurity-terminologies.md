<mark style="color:yellow;">Employees bringing and using their own devices, authorized by an organization.</mark>

<mark style="color:yellow;">On-demand availability of system or networked resources.</mark>
{% endtab %}

{% tab title="» Ciphertext" %}
<mark style="color:yellow;">A plaintext encrypted with an encryption algorithm.</mark>
{% endtab %}

{% tab title="» Confidentiality" %}
<mark style="color:yellow;">The state of keeping something private or secret.</mark>
{% endtab %}

{% tab title="» Cyber Essentials" %}
Industry-supported, Government-baked policies to help protect organizations against online threats.
{% endtab %}

{% tab title="» Data Breach" %}
The unintentional or intentional release of private or secure information.
{% endtab %}

{% tab title="» Decode" %}
To convert an encoded message into comprehensible language.
{% endtab %}

{% tab title="» Denial of Service (DoS)" %}
A cyber-attack that disrupts services by denying access to network resources or machines.
{% endtab %}

{% tab title="» Exfiltration" %}
Transfer of data without consent, or explicit authorization.
{% endtab %}

{% tab title="» Ethernet" %}
The architecture for interconnecting computer systems via a wired local area network
{% endtab %}

{% tab title="» EUD (End-User Device)" %}
A device capable of storing information, such as a PC, laptop, smartphone, tablet, hard drive, memory card, or USB flash drive.
{% endtab %}

{% tab title="» Exploit" %}
An attempt to breach secure networks to gain access to digital assets.
{% endtab %}

{% tab title="» Forensics" %}
An application of analysis and investigation to gather evidence from computing devices.
{% endtab %}

{% tab title="» Firewall" %}
A security system that controls and monitors outgoing and incoming network traffic in conformity with predetermined rules.
{% endtab %}

{% tab title="» GDPR (General Data Protection Regulation)" %}
General Data Protection Regulation – a law that regulates how organizations protect the personal data of EU citizens.
{% endtab %}

{% tab title="» Hacker" %}
A cybercriminal who uses electronic devices to obtain unauthorized data access
{% endtab %}

{% tab title="» Hashing" %}
An algorithm applied to data to validate that the information is not corrupted, tampered, or modified.
{% endtab %}

{% tab title="» ISO 27001" %}
A globally recognized standard for risk management of information security as per the ISMS (Information Security Management System) procedures and policies. ISO 27001 accreditation proves to stakeholders and clients that an organization is managing information security effectively
{% endtab %}

{% tab title="» ICT (Information and Communications Technology)" %}
An extended term for IT, stresses unified communications, such as the integration of computers, mobile phones, wireless networks, the internet, middleware, enterprise software, and media applications.
{% endtab %}

{% tab title="» Integrity" %}
This refers to data that has not been tampered or modified.
{% endtab %}

{% tab title="» Jailbreak" %}
A process of removing device security restrictions, allowing its user to make modifications.
{% endtab %}

{% tab title="» Keystroke Logging" %}
Also called keylogging, it refers to capturing a computer user’s keystrokes on a keyboard.
{% endtab %}

{% tab title="» Logic Bomb" %}
A code inserted to set off malicious functions in software systems.
{% endtab %}

{% tab title="» Macro Virus" %}
A virus programmed in the macro language. Microsoft Excel and Word are common applications featuring macro languages.
{% endtab %}

{% tab title="» Malware" %}
Malicious software designed for disrupting, damaging, or gaining unauthorized access
{% endtab %}

{% tab title="» Network" %}
Connected computers linked through the internet.
{% endtab %}

{% tab title="» NIS Directive" %}
A European Union directive on the security of information systems and networks.
{% endtab %}

{% tab title="» NIST CSF (NIST Cybersecurity Framework)" %}
National Institute of Standards and Technology (NIST) guidelines for US private enterprises to follow for improved detection and response to cyber-attacks.
{% endtab %}

{% tab title="» Outsider Threat" %}
An external security threat by a group or an individual.
{% endtab %}

{% tab title="» Penetration Testing" %}
Often referred to as ethical hacking, it is a simulated cyber-attack to assess a system’s security.
{% endtab %}

Malicious software that disrupts a system and demands a ransom to make it workable again.
{% endtab %}

{% tab title="» SaaS (Software-as-a-Service)" %}
A software delivery model on the cloud on a subscription basis.
