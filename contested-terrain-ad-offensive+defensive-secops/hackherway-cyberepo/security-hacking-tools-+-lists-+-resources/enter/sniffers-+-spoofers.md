# Sniffers + Spoofers

#### Packet Sniffing and Spoofing Tools

* [Wireshark](https://www.wireshark.org/): A free and open-source network protocol analyzer and packet capture tool. Wireshark allows users to inspect hundreds of protocols and dozens of file formats.
* [tcpdump](https://www.tcpdump.org/): A free and open-source command-line network packet analyzer. Users can specify a particular filter to search for packets that match this description
* [Ettercap](https://www.ettercap-project.org/): A free and open-source comprehensive suite for man-in-the-middle attacks. Ettercap offers both a command-line and GUI interface and includes features such as live packet sniffing and content filtering.
* [Bettercap](https://www.bettercap.org/): A free and open-source fork of the Ettercap project and so-called “Swiss Army knife” for network attacks. Bettercap can be used on Wi-Fi networks, Bluetooth connections, and 2.4GHz wireless devices
* [Snort](https://www.snort.org/): A free and open-source intrusion detection and prevention system. Users can define rules in Snort that indicate malicious network activity and search for packets that match these rules.
* [Ngrep](https://github.com/jpr5/ngrep): A free and open-source network packet analyzer that uses grep-like patterns. The ngrep tool supports many different protocols across a wide range of interface types.
* [NetworkMiner](https://www.netresec.com/?page=NetworkMiner): A free and open-source network forensic analysis tool. NetworkMiner can extract files, images, emails, passwords, and more from network traffic in PCAP files.
* [Hping3](https://www.kali.org/tools/hping3/): A free and open-source command-line packet crafting and analysis tool. The hping3 tool can send custom ICMP/UDP/TCP packets for use cases such as testing firewalls or network performance.
* [Nemesis](https://github.com/libnet/nemesis): A free and open-source packet crafting and injection tool, Nemesis supports many different protocols and can be used for Layer 2 injection on both Windows and Linux systems.
