# Active Directory Enumeration Tips and Tricks

## AD Enumeration

* AD initial enumeration and exploitation is similar to stand-alone machines.
* Identify the target machine's role (DC/client) and the services present.
* Identify the initial target into the domain (the low-hanging fruit).

## AD Exploitation

* Have a cheatsheet of AD commands.
  * Be thorough for enumeration, exploitation, and post-exploitation purposes.
* Do not ignore standard enumeration, check applications and non-AD-related services.
* Try using information you obtained on multiple domain targeted machines.

## Document and Backup

* Document all commands, outputs, scripts, and code you use.
  * User terminal loggers to automatically log all commands and outputs in your shell.
* Take snapshots and backups of your work.
* Remember: ongoing documentation saves time from rerunning any commands if you need the outputs again.
