# Software Dependencies and Development Tools

Adversaries may manipulate software dependencies and development tools within the supply chain, aiming to compromise data or systems. Applications often rely on external software dependencies to operate effectively. Popular open source projects used as dependencies in numerous applications may be targeted to introduce malicious code to users of the dependency.

These manipulations in the supply chain can be tailored for specific victims or distributed broadly, with the adversary activating additional tactics only on specific targets. Targeting software dependencies poses a significant threat, as it can impact a wide range of applications and their users.
