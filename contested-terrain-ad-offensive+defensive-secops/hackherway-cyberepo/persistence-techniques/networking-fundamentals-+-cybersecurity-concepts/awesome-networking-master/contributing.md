# CONTRIBUTING

Please read carefully the guides for contributing to this project. Before you create a Pull Request, search for already created ones so there won't be any duplicate.

Add only courses, books, software that you really think is awesome — don't just add any resource that contains words like "Network, Networking, etc.". It is even better if you have personal experience with the resource, because after all, this is a list of awesome things.

{% hint style="danger" %}
If you are adding a book, software, or any other purchasable resource, **DO NOT** add links that lead to illegal sites or illegal resources. Provide a link to the official shop/author website or another official seller of that content (for example, a book on Amazon).
{% endhint %}

## Guidelines

{% stepper %}
{% step %}
### Find the resource link

Find a link to the resource you consider awesome.
{% endstep %}

{% step %}
### Add it to the proper category

Add it to the proper category at the end of the list (two new).
{% endstep %}

{% step %}
### Use the required format

Use the format:

* [name](http://example.com/) - A short description ends with a period.
{% endstep %}

{% step %}
### Add new sections when needed

If there is no section for your resource but you think there should be, add it right before the **Miscellaneous** category.
{% endstep %}

{% step %}
### Check spelling and grammar

Check your spelling and grammar.
{% endstep %}

{% step %}
### Send a proper Pull Request

Send a Pull Request with a proper name and description (**Do not name Pull Request like "Update Readme.md"**).
{% endstep %}

{% step %}
### Be patient

Be patient. It may take a few days for me to review it.
{% endstep %}
{% endstepper %}
