Pick one of the following full-course lecture playlists:

* Stanford: [Introduction to Computer Networking](https://www.youtube.com/playlist?list=PLoCMsyE1cvdWKsLVyf6cPwCLDIZnOj0NS)

Stanford teaches top-down (application → physical). Wetherall teaches bottom-up (physical → application). Personally worked through Wetherall.

#### Assignments & Projects

Use course assignments and implement networking programs and protocols:

* [Princeton's Computer Networks repository](https://github.com/PrincetonUniversity/COS461-Public)
* [Stanford CS144 - Fall 2010](https://www.scs.stanford.edu/10au-cs144/)

Project ideas:

* Implement common networking tools (ping, traceroute)
* Implement parts of networks/protocols (e.g., spanning tree protocol)
* Recreate or implement selected RFCs and analyze with Wireshark
